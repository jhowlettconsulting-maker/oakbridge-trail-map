# Oakbridge Trail Map

Course pathway map v7, including the course descriptions. The supplied HTML is preserved unchanged.

[Open the public map](https://jhowlettconsulting-maker.github.io/oakbridge-trail-map/)

## Wix embed

Paste this into a Wix Embed HTML element. Set the Wix element to full width and 900 px high; adjust its height for your layout. The map switches layouts automatically for narrow screens and scrolls inside the frame.

```html
<iframe
  src="https://jhowlettconsulting-maker.github.io/oakbridge-trail-map/"
  title="The Oakbridge Path — Course Trail Map"
  width="100%"
  height="900"
  style="display:block;width:100%;border:0;"
  loading="lazy">
</iframe>
```
